一、XXE入口

登录抓包分析 .net站点 xml语法

构造报错 看异常回显 说明是直接解析 不是字符串匹配

思路

  • 报 XML 语法错 → 有 XML 解析器 → 测 XXE；
  • 报 SQL 语法错 → 有 SQL 执行 → 测注入；
  • 报 模板渲染错 → 有模板引擎 → 测 SSTI；

测试DTD是否开启 正常回显错误账密 说明 &x;被成功替换为ABC的值→ 内部实体可用 → DTD 处理是开启的。

如果 DTD 被禁用，你会看到类似”DTD 被禁止”的报错，或直接报错。“能解析不报错”本身就是”DTD 开着”的证据。

XXE文件读取 外部实体塞入属性值 .net的XmlDocument默认不允许外部实体出现在属性值里
